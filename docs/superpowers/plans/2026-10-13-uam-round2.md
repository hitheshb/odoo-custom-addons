## Global Constraints

- Module `user_access_management`, Odoo 20; new admin features visible to `base.group_system` only.
- Signal palette: teal `#0E9F8E` (active/online/original), amber `#D99A1E` (warning/away/copy/expiring), crimson `#B42339` (needs action/stale/locked), indigo `#3554D1` (links/accent). Surfaces use Bootstrap theme vars (`--bs-body-bg`, `--bs-border-color`, `--bs-secondary-color`, `--bs-tertiary-bg`).
- Icons: Odoo 20 `oi` font only: `<span class="oi" data-icon="NAME"/>`. No `fa` classes anywhere (they render blank).
- OWL templates: `t-out`, never `t-esc`.
- Config params use typed API: `get_int(key, default)` / `set_int`. Setting an Integer config field to 0 stores 0 (res_config.py `set_int`).
- Binary reads return BinaryValue (`.content`).
- `act_window` `target="inline"` is invalid.
- Unique constraints: `models.Constraint(...)`. Translations: `self.env._(...)`.
- Times shown to people: `odoo.tools.format_datetime(self.env, value)` (user tz).
- Print retention default 180 days, key `user_access_management.print_retention_days`, 0 = keep forever.
- Timeline: last 50 events. Temp-access warning: check every 15 minutes; `warning` type when < 24 h left; re-shown once when < 1 h left.
- Tests: `cd /home/hithesh/odoo20/custom-addons && scripts/test_module.sh user_access_management` (sandbox disabled; exit code = pass/fail). A live server may share the db: re-run once on "could not serialize access". Never run raw SQL against the db yourself.

    user_id = fields.Many2one('res.users', ondelete='cascade', index=True)
    group_id = fields.Many2one('res.groups', string='Group', ondelete='cascade', index=True,
                               help="Lock everyone in this group, including people who join later.")

                                  compute='_compute_lock_state')

    @api.depends('active', 'forever', 'date_until')
    def _compute_lock_state(self):
        now = fields.Datetime.now()
        for lock in self:
            if not lock.active or (not lock.forever and lock.date_until and lock.date_until <= now):
                lock.lock_state = 'expired'
            else:
                lock.lock_state = 'forever' if lock.forever else 'active'

    @api.constrains('user_id', 'group_id', 'model_id')
    def _check_target(self):
        admins = self.env.ref('base.group_system').all_user_ids
        for lock in self:
            if bool(lock.user_id) == bool(lock.group_id):
                raise ValidationError(self.env._('Choose either a user or a group, not both.'))
            if lock.model_id.model in PROTECTED_MODELS:
                raise ValidationError(self.env._('The Access Lock screen itself cannot be locked.'))
            targets = lock.user_id | lock.group_id.all_user_ids
            if lock.model_id.model in ADMIN_MODELS and targets & admins:
                raise ValidationError(self.env._(
                    'This lock would block an administrator from managing users and rights.'))

    def action_unlock(self):
        self.active = False

    def _extend(self, delta):
        now = fields.Datetime.now()
        for lock in self.filtered(lambda l: not l.forever):
            lock.date_until = max(lock.date_until or now, now) + delta
            lock.active = True

    def action_extend_day(self):
        self._extend(timedelta(days=1))

    def action_extend_week(self):
        self._extend(timedelta(weeks=1))

    def _compute_uam_stats(self):
        for user in self:
            user.uam_lock_count = self.env['uam.access.lock'].search_count(user._uam_lock_domain())
            user.uam_temp_count = self.env['user.temp.access'].search_count([('user_id', '=', user.id)])

    @api.depends('date_from', 'date_to', 'state')

            left = (t.date_to - now).total_seconds() if t.date_to else 0
